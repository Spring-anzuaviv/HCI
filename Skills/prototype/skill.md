# Skill Prototype Builder

## Purpose
Tạo file HTML/CSS/JS thuần (vanilla) đóng vai trò là bản Prototype (Low-Fidelity) cho đồ án HCI.
Bản Prototype này đứng trước Wireframe, có nhiệm vụ xây dựng bộ khung xương (skeleton) trắng đen để test luồng tương tác cơ bản (giải quyết P1, P3, P4) mà không bị chi phối bởi thiết kế màu sắc.

## Use This Skill When
- Cần tạo bản khung trắng đen ban đầu cho luồng tương tác.
- Cần làm rõ Information Architecture và User Flow trước khi đắp màu (Wireframe).

## Required Inputs
- Các pain points cần giải quyết.
- Ràng buộc: Không sử dụng thư viện bên thứ 3 (như React, Tailwind).

## Output
- File lưu tại: `outputs/prototype.html`
- Giao diện KHÔNG có màu sắc (chỉ đen trắng xám), cấu trúc rõ ràng.

## Domain Knowledge
- **Hàng đợi thông minh & Cảnh báo:** Chỉ cần mô phỏng bằng text/layout dạng text mộc.

## Reasoning Rules
1. **Không dùng Framework:** Chỉ dùng HTML/CSS/JS thuần.
2. **Thiết kế Low-Fi (Trắng đen):** Tuyệt đối không dùng bảng màu thương hiệu, chỉ dùng tone xám/đen.
3. **Dữ liệu hardcode:** Mô phỏng đơn hàng tĩnh.
